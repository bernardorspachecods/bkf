# Run to completion

The user is leaving. This is the last interaction; after it, you decide.

## Before they go

Tell them in one short message:
- what you still need from them, if anything;
- where you will stop;
- what will make you stop.

If you need something, wait for the answer. If not, start right away, without asking for a go.

## After

- Decide yourself. Pick the option that best fits the user's goal and what you had already decided, and record each decision and why.
- The checkpoints of the workflow in use still apply, except where they require the user.
- Stop only if it is fundamental: an irreversible action or one outside what was authorized, or the intent no longer holds. Before stopping, finish what does not depend on the answer and leave the state written down.
- At the end, one report: done and not done, how it was checked, the decisions, what is unresolved. Say plainly what failed or was skipped.
