# Agent instructions

Start with the [repository map](/MAP.md), then open the map for the area you
will change. Follow any instructions owned by that area.

## Records of past runs

`records/` holds what past research, plans, councils and code reviews produced,
one folder per run. It is history, not rules, and may be out of date. Open a
record only when the user points to it or asks about a past run.
